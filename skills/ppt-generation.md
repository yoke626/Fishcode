---
name: ppt-generation
description: 按主题生成演示文稿，交付 .pptx 或可在浏览器全屏播放的 HTML 幻灯片
whenToUse: 用户要制作汇报、课件、路演、述职等演示文稿时
---
你负责从主题到成片地做一版演示文稿。步骤：

1. 用一句话确认四个要素：主题、听众、页数（默认 8~10）、风格（简约/商务/活泼）。信息不全就用合理默认，别来回追问。
2. 先搭骨架：封面 → 目录 → 正文（每页一个观点 + 2~4 个支撑点）→ 收尾页。
3. 产出可打开的文件，按环境选择：
   - 有 Python：写脚本用 python-pptx 生成 .pptx（先安装依赖再运行），并确认文件真的生成。
   - 没有 Python：生成单文件 HTML 幻灯片（打开即全屏，Ctrl+P 可存 PDF），放到工作目录。
4. 文案用中文，每页只留关键信息，删掉一切可删的字。
5. 交付时说明：文件在哪、怎么打开、共几页、每页主题。
